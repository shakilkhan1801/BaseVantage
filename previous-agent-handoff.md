## 2. The old agent's plan and key design decisions

The full reasoning is in `previous-agent-plan.md` (§ "Agent-Replay"). The plan was
11 phases: env check → design-doc corrections + scaffold + commit 0 → error/config →
core types + L1 → venues quoters/encoders → L2 market → L3 router → L4 safety →
L7 watchlist → harness CLI → tests + gates + report. Notable engineering decisions:

- Single crate (lib + `bv` bin); `alloy` 1.x + tokio/serde/toml/clap/thiserror/tracing;
  `async-trait` for a dyn-compatible `ChainAdapter` so test doubles can wrap it.
- **Quoters compute locally from cached state** (not per-quote `eth_call`): v2 and
  aerodrome from reserves (aerodrome stable math = the deployed Solidly Newton loop,
  `_f` vs `_k` variant verified against the deployed contract's source), v3/v4 full
  concentrated-liquidity swap math ported from core (TickMath/SwapMath, U256/U512
  mul_div with exact rounding), v4 pool state read via `PoolManager.extsload` on
  computed storage slots (`POOLS_SLOT = 6`, PoolId = keccak of the PoolKey).
- **Encoders are hand-rolled** (full control, byte-exact) with an independent
  `sol!`-generated encoding cross-checked in tests — the "byte-identical pin" goldens
  in `fixtures/calldata/` therefore cover the exact bytes sent. Golden files were
  generated by the test suite itself (`BV_REGEN_GOLDEN=1 cargo test --test encoding`)
  after all sol! byte-equality assertions passed.
- Venue targets on Base: Uniswap V2 router `0x4752ba5D…`, V3 SwapRouter02
  (`exactInputSingle` selector `0x04e45aaf`), V4 via Universal Router
  `0x6fF5693b…` command `0x10` (V4_SWAP), Aerodrome router `0xcF77a3Ba…`.
  Mixed-venue route encoding is refused in S1; v4 hook-pools are skipped in discovery.
- Token assess runs buy/sell probes via `eth_call` (state overrides), floor module
  anchors at REFERENCE + SWAP (+ TARGET when supplied), min-out = max of applicable
  anchors, enforced in calldata and re-checked in sim.
- Watchlist persists to one JSON file behind a trait; stats come from a pluggable
  `StatsSource` (default returns None → negative-cached).
- Deviations it flagged itself: `bench()` made `async` (design sketch had it sync);
  `src/market/abi.rs` added to the layout (sol! declarations); fork tests live in a
  single `tests/fork.rs` to preserve the exact `fork::*` test names; goldens are
  self-generated but two-path verified (manual encoder == sol! == fork execution).
